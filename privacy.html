1. English Version (Microsoft Store Policy 10.5 Compliance)

1.1 Overview — Zero Telemetry & Local-First Operation

Our 3D Desktop Companion applications run on your Windows 10/11 device with AI off by default. The publisher (Julio-Patrón) does not operate remote backend servers for these applications and does not collect, transmit, store, rent, or sell any personal data, usage analytics, crash telemetry, device identifiers, keystrokes, screen captures, voice recordings, or conversation logs.

1.2 Offline Default State (aiEnabled: false)

Out of the box, every application launches with Artificial Intelligence turned OFF (aiEnabled: false). While AI is turned off:

  • Zero network requests are initiated by the application.
  • Screen capture, clipboard reading, and microphone input are strictly disabled at the application session level.
  • Companion state (active days, bond level, window placement), custom workflow presets, and local notes (memoria.md) are stored exclusively inside your own local Windows user profile directory.

1.3 Optional Bring-Your-Own-Key (BYOK), Local AI & User-Initiated Screen Snipping

If you explicitly choose to enable AI in Settings (⚙️ Ajustes → 🔑 Inteligencia Artificial), you connect your own preferred provider directly from your PC:

  • Local Ollama / Local API (http://localhost:11434/v1): All prompts, dropped files, and screen snips remain strictly on your local machine with zero external network traffic.
  • Third-Party Cloud APIs configured by you (Google Gemini API or OpenAI-compatible endpoint): When you use AI, your PC sends the selected text, audio, screen snips or attachments to your configured provider. Requests can also include conversation history, your previous reply, role instructions, companion activity, project notes and saved memory. The provider processes that information under its own terms.
  • Graphics Capture Permission (graphicsCaptureProgrammatic): Used exclusively when you manually trigger an interactive screen-region snip (Alt+Shift+S or the Snip button) while AI is enabled. The application never captures screens in the background, and you may revoke screenshot access at any time in Windows Settings → Privacy & security → Screenshots and screen recording.

In Store build 1.1.3, dropping a folder with AI enabled includes files in its subfolders. Entries inside folders whose names start with a dot are skipped. Gemini receives the selected PDFs directly. Text-only providers receive text extracted on your device. The app creates the Excel workbook locally when you choose to save it.

1.4 Local Credential Protection (Windows DPAPI) & Origin Binding

  • Any API key you save in Settings is encrypted locally at rest on your Windows device using Windows Data Protection API (DPAPI) bound to your Windows user account.
  • Keys saved for a custom compatible server are bound to that exact server origin and are never transmitted if you change the endpoint URL.
  • Exported Personality Cartridges (.json / .md) contain only role prompts and workflow recipes; they never include API keys, server URLs, or your private memoria.md file.

1.5 User Control, Data Deletion & Contact

  • View, edit, or wipe memoria.md directly from Settings (🗑️ Vaciar memoria), and clear any saved API key in one click.
  • Uninstalling the application from Windows Settings → Apps → Installed apps cleanly removes the MSIX package container and its local application data.

2. Versión en Español (Cumplimiento Política 10.5 de Microsoft Store)

2.1 Resumen — Cero Telemetría y Operación 100% Local

Nuestras aplicaciones de Compañeros 3D de Escritorio se ejecutan en tu equipo Windows 10/11 con la IA apagada de fábrica. El editor (Julio-Patrón) no opera servidores remotos para estas aplicaciones ni recopila, transmite, almacena, alquila ni vende datos personales, telemetría de uso, identificadores del dispositivo, capturas de pantalla, audio ni historiales de conversación.

2.2 Estado Offline de Fábrica (aiEnabled: false)

Al instalar y abrir cualquiera de las aplicaciones, la Inteligencia Artificial viene apagada de fábrica (aiEnabled: false). Mientras la IA está apagada:

  • La aplicación no realiza ninguna conexión de red externa.
  • La captura de pantalla, lectura de portapapeles y uso de micrófono permanecen deshabilitados.
  • Tus preferencias, progreso de interacción y archivo memoria.md se guardan exclusivamente en la carpeta local de tu usuario en Windows.

2.3 Proveedores de IA Opcionales (BYOK / Ollama Local) y Recorte de Pantalla

Si decides activar manualmente la IA en ⚙️ Ajustes → 🔑 Inteligencia Artificial, conectas tu propio proveedor directamente desde tu PC:

  • Ollama local (http://localhost:11434/v1): Todo el procesamiento permanece 100% dentro de tu propio equipo sin salir a internet.
  • Proveedores en la nube configurados por ti (Google Gemini u OpenAI compatible): Cuando usas la IA, tu PC envía al proveedor configurado el texto, audio, recorte de pantalla o adjunto que elijas. La petición también puede incluir el historial, la respuesta anterior, instrucciones de rol, actividad del compañero, notas del proyecto y memoria guardada. El proveedor procesa esos datos según sus propias condiciones.
  • Permiso de captura gráfica (graphicsCaptureProgrammatic): Se utiliza exclusivamente cuando tú inicias manualmente un recorte de área (Alt+Shift+S) con la IA encendida. Jamás se realizan capturas en segundo plano y puedes administrar este permiso en cualquier momento desde Configuración de Windows → Privacidad y seguridad → Capturas de pantalla.

En la compilación Store 1.1.3, soltar una carpeta con la IA activa incluye los archivos de sus subcarpetas. Se omiten las entradas dentro de carpetas cuyo nombre empieza por punto. Gemini recibe los PDF seleccionados directamente. Los proveedores de texto reciben el texto extraído en tu equipo. La aplicación crea el libro de Excel localmente cuando eliges guardarlo.

2.4 Cifrado Local de Credenciales (DPAPI), Control de Datos y Contacto

  • Las claves API guardadas se cifran localmente en disco mediante Windows DPAPI, vinculadas a tu sesión de usuario en Windows, y quedan asociadas únicamente al dominio del servidor para el que se guardaron.
  • Los Cartuchos de Personalidad (.json / .md) nunca incluyen claves, URLs ni tu archivo privado memoria.md.
  • Puedes inspeccionar, editar o vaciar memoria.md y borrar claves guardadas desde ⚙️ Ajustes, o eliminar todos los datos desinstalando la aplicación desde Windows.
